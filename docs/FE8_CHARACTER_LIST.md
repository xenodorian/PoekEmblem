# FE8 Character Master List

Generic or unnamed entries are excluded: Citizen, Soldier, Messenger, Monster, Enemy, Bandit, Bone, and the Phantom summons. Each name below is one character. Variant IDs (suffixes `_CC`, `_CH5X`, `_FINAL`, `_PROLOGUE`, `_2`) are the same name at a different point in the game, so they are grouped together.
