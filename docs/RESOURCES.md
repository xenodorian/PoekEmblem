## FireRed Hacking Basics
- PokeCommunity ROM hacking help: https://www.pokecommunity.com/threads/rom-hacking-help.414127
- PokeCommunity hex and free space thread: https://www.pokecommunity.com/threads/em-hex-values-and-free-space.436335
- PokeCommunity basic hex/ASM concepts: https://www.pokecommunity.com/threads/basic-hexadecimal-asm-knowledge-concepts-for-beginning-rom-hackers.345692/
- PokeCommunity ROM hacking tools pack (FireRed and Emerald): https://www.pokecommunity.com/threads/rom-hacking-tools-pack-all-the-essentials-to-hack-fire-red-and-emerald.527579/
- Notes: use HxD or any hex editor, FreeSpaceFinder to locate free space, paste-insert (not paste-write) so file size is kept, and keep backups.
