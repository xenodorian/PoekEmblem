# FireRed Character Master List (in-game trainers)

Source: `src/data/trainers.h` (trainer names and classes) cross-checked against trainer IDs referenced in `data/maps` from pret/pokefirered (shallow clone, 2026-10-15). Only trainers that appear in map scripts are listed. Trainer definitions in `trainers.h` with no map reference (Hoenn-era Roxanne, Brawly, Aqua/Magma admins, and others) are excluded.

Not included: named NPCs who are not trainers (Professor Oak as a field NPC, Mom, Bill, Daisy's house, Silph staff). Those come from object event text and still need a separate pass.

Total in-game trainer entries: 253. Unique names: 169.
